# smart-auth

**БЕТА — тестування ще триває. Використовуйте на власний ризик.** Можлива втрата даних, предметів, коштів або доступу до акаунтів. Створіть резервну копію та перевірте автоматичні дії перед використанням.

[English](README.md) · **Українська** · [Русский](README.ru.md)

Автентифікатор Steam для Windows із зашифрованим локальним сховищем, окремими проксі для акаунтів, підтвердженнями обмінів і дій на ринку, постійними браузерними профілями, автоматизацією Loot та менеджерами паролів і 2FA.

**Поточна версія: 0.14.4-beta.5.** Інтерфейс підтримує англійську, українську та російську мови. Основна мова документації — англійська; версії README українською та російською доступні за посиланнями вгорі. Переклади застосунку зберігаються окремо в `src/locales/`.

## Можливості

- Коди Steam Guard, папки акаунтів, нотатки, імпорт, експорт і масові дії.
- Окремі маршрути проксі, розподіл між акаунтами папки, резервні проксі та перевірка їхньої доступності. Прямі підключення до Steam типово вимкнені.
- Перегляд і підтвердження запитів ринку та обмінів із даними про предмети й контрагентів; налаштування періодичних перевірок та автоматизації.
- Постійні браузерні профілі з окремими вебсесіями, проксі відповідного акаунта й налаштуваннями розширень.
- Паралельні схеми Loot із вибором джерел і складів, обробкою кожного джерела, повторними спробами та відображенням прогресу.
- Локальний менеджер паролів, генератор паролів та окремий менеджер TOTP/HOTP для сервісів, не пов’язаних зі Steam.
- Зашифроване сховище, необов’язкові TOTP і PIN для входу в застосунок, автоматичне блокування інтерфейсу, дії з трея, світла й темна теми.

У **Налаштування → Браузер Chromium → Локальні розширення ZIP** натисніть **Додати ZIP…**, перевірте назву, версію та стан і збережіть налаштування. Перевідкрийте активні браузери акаунтів для застосування. Smart Trader керується окремо. Додавайте лише довірені пакети; обмеження й резервне копіювання описано в [посібнику (EN)](docs/USER-GUIDE.md#local-zip-extensions).

## Початок роботи

Використовуйте `smart-auth-0.14.4-beta.5-win-x64.exe` з підготовлених файлів релізу або з розділу Releases після публікації. Для EXE не потрібен Node.js. Звірте завантажений файл із контрольною сумою в супровідному `SHA256SUMS.txt`.

1. Прочитайте [ліцензію](LICENSE) та [примітки щодо поширення](docs/DISTRIBUTION-NOTES.md).
2. Повністю закрийте попередню версію, зокрема процес у треї, і запустіть EXE.
3. Створіть або розблокуйте локальне сховище. Збережіть пароль та інформацію для відновлення в надійному місці.
4. Імпортуйте акаунти з автентифікаторами, налаштуйте їхні проксі та перевірте маршрути перед увімкненням автоматизації.
5. Перегляньте налаштування акаунтів і автоматизації. Перед масовими операціями створіть незалежну резервну копію.

Наявні встановлення зазвичай зберігають дані в `%APPDATA%\Smart SDA`, окремо від портативного EXE. Оновлення виконуваного файла не потребує повторного імпорту акаунтів. Блокування інтерфейсу приховує всі вікна застосунку, але вже запущений Loot і налаштовані періодичні перевірки продовжують працювати. Повний вихід із застосунку зупиняє фонову роботу. Відомості про резервні копії та обмеження браузерних профілів наведено в [посібнику користувача](docs/USER-GUIDE.md). Нові встановлення зазвичай використовують `%APPDATA%\smart-auth`. Сховище або резервна копія в початковому каталозі мають пріоритет; порожній початковий каталог не приховує сховище в новому каталозі. Дані не переміщуються й не поєднуються.

## Збірка для Windows x64

Використовуйте **Node.js 24** і **pnpm 11.25.0**:

```powershell
pnpm install --frozen-lockfile
pnpm check
pnpm dist
```

EXE буде створено в `release/smart-auth-0.14.4-beta.5-win-x64.exe`. EXE та архів вихідного коду не містять файлів браузера Google Chrome. Під час першого відкриття браузера акаунта застосунок запропонує завантажити його безпосередньо з Google після прийняття умов Google; наступні запуски використовують локальний кеш відповідної версії. Збірка й перевірки виконуються локально; GitHub Actions для цього репозиторію не потрібен. Докладніше — в [інструкції зі збірки](docs/BUILD.md).

Підготовлений архів вихідного коду містить код застосунку та інструменти збірки. Результати збірки виключено з Git. Портативний EXE завантажується окремо з файлів релізу.
