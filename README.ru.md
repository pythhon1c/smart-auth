# smart-auth

**БЕТА — тестирование ещё продолжается. Используйте на свой риск.** Возможна потеря данных, предметов, средств или доступа к аккаунтам. Создайте резервную копию и проверьте автоматические действия перед использованием.

[English](README.md) · [Українська](README.uk.md) · **Русский**

Аутентификатор Steam для Windows с зашифрованным локальным хранилищем, отдельными прокси для аккаунтов, подтверждениями обменов и действий на рынке, постоянными браузерными профилями, автоматизацией Loot и менеджерами паролей и 2FA.

**Текущая версия: 0.14.4-beta.5.** Интерфейс поддерживает английский, украинский и русский языки. Основной язык документации — английский; версии README на украинском и русском доступны по ссылкам вверху. Переводы приложения хранятся отдельно в `src/locales/`.

## Возможности

- Коды Steam Guard, папки аккаунтов, заметки, импорт, экспорт и массовые действия.
- Отдельные маршруты прокси, распределение между аккаунтами папки, резервные прокси и проверка их доступности. Прямые подключения к Steam по умолчанию отключены.
- Просмотр и подтверждение запросов рынка и обменов с данными о предметах и контрагентах; настройка периодических проверок и автоматизации.
- Постоянные браузерные профили с отдельными веб-сессиями, прокси соответствующего аккаунта и настройками расширений.
- Параллельные схемы Loot с выбором источников и складов, обработкой каждого источника, повторными попытками и отображением прогресса.
- Локальный менеджер паролей, генератор паролей и отдельный менеджер TOTP/HOTP для сервисов, не связанных со Steam.
- Зашифрованное хранилище, необязательные TOTP и PIN для входа в приложение, автоматическая блокировка интерфейса, действия из трея, светлая и тёмная темы.

В **Настройки → Браузер Chromium → Локальные расширения ZIP** нажмите **Добавить ZIP…**, проверьте название, версию и состояние и сохраните настройки. Переоткройте активные браузеры аккаунтов для применения. Smart Trader управляется отдельно. Добавляйте только доверенные пакеты; ограничения и резервное копирование описаны в [руководстве (EN)](docs/USER-GUIDE.md#local-zip-extensions).

## Начало работы

Используйте `smart-auth-0.14.4-beta.5-win-x64.exe` из подготовленных файлов релиза или из раздела Releases после публикации. Для EXE не нужен Node.js. Сверьте загруженный файл с контрольной суммой в сопроводительном `SHA256SUMS.txt`.

1. Прочитайте [лицензию](LICENSE) и [примечания о распространении](docs/DISTRIBUTION-NOTES.md).
2. Полностью закройте предыдущую версию, включая процесс в трее, и запустите EXE.
3. Создайте или разблокируйте локальное хранилище. Сохраните пароль и информацию для восстановления в надёжном месте.
4. Импортируйте аккаунты с аутентификаторами, настройте их прокси и проверьте маршруты перед включением автоматизации.
5. Проверьте настройки аккаунтов и автоматизации. Перед массовыми операциями создайте независимую резервную копию.

Существующие установки обычно сохраняют данные в `%APPDATA%\Smart SDA`, отдельно от портативного EXE. Обновление исполняемого файла не требует повторного импорта аккаунтов. Блокировка интерфейса скрывает все окна приложения, но уже запущенный Loot и настроенные периодические проверки продолжают работать. Полный выход из приложения останавливает фоновую работу. Информация о резервных копиях и ограничениях браузерных профилей приведена в [руководстве пользователя](docs/USER-GUIDE.md). Новые установки обычно используют `%APPDATA%\smart-auth`. Хранилище или резервная копия в исходном каталоге имеют приоритет; пустой исходный каталог не скрывает хранилище в новом каталоге. Данные не переносятся и не объединяются.

## Сборка для Windows x64

Используйте **Node.js 24** и **pnpm 11.25.0**:

```powershell
pnpm install --frozen-lockfile
pnpm check
pnpm dist
```

EXE будет создан в `release/smart-auth-0.14.4-beta.5-win-x64.exe`. EXE и архив исходного кода не содержат файлов браузера Google Chrome. При первом открытии браузера аккаунта приложение предложит загрузить его напрямую с Google после принятия условий Google; следующие запуски используют локальный кеш соответствующей версии. Сборка и проверки выполняются локально; GitHub Actions для этого репозитория не нужен. Подробнее — в [инструкции по сборке](docs/BUILD.md).

Подготовленный архив исходного кода содержит код приложения и инструменты сборки. Результаты сборки исключены из Git. Портативный EXE загружается отдельно из файлов релиза.
