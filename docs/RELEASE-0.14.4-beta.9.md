# smart-auth 0.14.4-beta.9

**Beta software, still under testing. Use at your own risk.** Back up the encrypted vault before upgrading.

- The **One .maFile** import source has a dedicated **Choose .maFile** button that opens the native picker for one authenticator file.
- File, multiple-file, and folder sources have explicit picker buttons before **Review**. The dialog shows the selected file, the first filename and total for multiple files, or the bulk import folder.
- Select the file, optionally add a Steam password and individual proxy, then choose **Review** and **Apply** to complete the import.

See the [user guide](USER-GUIDE.md) and [Windows build instructions](BUILD.md).
